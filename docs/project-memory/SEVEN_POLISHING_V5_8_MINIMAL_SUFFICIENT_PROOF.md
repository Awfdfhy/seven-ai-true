# Seven Polishing V5.8 — Minimal Sufficient Proof

Status: ARCHITECTURE_CANDIDATE
Parent: V5.7 Epistemic Stress

V5.8 attacks a new enemy created by the polishing system itself: proof bloat. A system can become so elaborate that evaluation cost, duplicated gates and documentation overhead delay Seven more than they protect it.

## Prime law
Use the smallest evidence set that preserves the same material detection power, authority protection and claim validity.

## Architecture
- ProofGraph maps claims to independent evidence families and invalidation triggers.
- Dominance pruning removes a gate only when another gate demonstrably subsumes its protected failure family under the same scope.
- Criticality floor prevents compression of C0/C1 protections merely for speed.
- Evidence reuse requires identity, freshness and environment compatibility.
- Incremental revalidation reruns impacted proof plus mandatory sentinel/broad checks.
- Sentinel suite preserves cheap detection of cross-cutting regressions.
- Periodic full challenge audits the selector itself and detects missed dependencies.
- Stop-on-disproof prioritizes cheap decisive failures before expensive evidence.
- Parallel lanes run only when independence and resource contention permit.
- Research stops on marginal information value, not arbitrary source count.
- Candidate pruning removes dominated designs early while preserving at least one structurally diverse challenger when material uncertainty remains.
- Documentation is normalized into reusable contracts/ledgers rather than repeated prose.
- Every new governance mechanism declares its own expected detection benefit, cost and retirement condition.

## Anti-bloat test
A Simplifier Challenger attempts to remove, merge or replace every new V5.x mechanism. If removing a mechanism does not materially reduce detection, correctness, recovery, authority or claim calibration, the mechanism should not remain mandatory.

## Velocity truth
Fastest valid path is measured empirically. V5.8 does not assume fewer tests are better; it requires equal protected coverage for any claimed acceleration.

## Saturation preparation
V5.8 is eligible to begin independent saturation challenges only after its own proof-minimization rules no longer find obvious redundant governance. Any material constitution change resets saturation.

## Truth boundary
Architecture only. No runtime speedup is claimed until measured.
