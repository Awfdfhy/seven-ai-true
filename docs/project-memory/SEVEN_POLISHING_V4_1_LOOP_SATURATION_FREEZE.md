## Canonical laws added
1. Measurable material claims require comparable benchmark evidence when feasible.
2. Benchmarks are evidence, not authority.
3. No universal scalar score may hide critical regressions.
4. Benchmark contracts and critical gates are locked before comparison.
5. Material failures become permanent regression cases when testable.
6. Benchmark validity itself is evaluated; flaky/non-discriminating measures can be invalid.
7. Visual UI polish uses both structural and pixel/visual evidence.
8. Multimodal visual judgments remain derived evidence with uncertainty.
9. Screenshots cannot prove hidden semantics or runtime performance by themselves.
10. Golden images are references, not unquestionable truth.
11. Device-level claims require corresponding device-level evidence.
12. Benchmark/vision machinery remains selective/lazy and must not impose ordinary-path startup cost merely by existing.
13. Screenshot capture/evaluation obeys privacy and permission boundaries.
14. Protocol self-polish is allowed only under locked goals and bounded saturation.

## Architecture vs implementation
This freeze certifies only the protocol architecture within the documented search surface. It does not claim an implemented benchmark runner, screenshot pipeline, multimodal model integration, Android instrumentation, physical-device lab, or release proof.

## Canonical adoption
V4.1 supersedes V4 for new polishing campaigns at the architecture-governance level. V4 remains historical provenance and fallback reference. Existing V4 freezes remain valid historical candidates and do not automatically become implementation/device claims.

## Reopen triggers
- benchmark implementation contradicts architecture
- measurement methodology invalidation
- visual evaluator drift/bias
- new material UI/device/accessibility failure
- Goodhart/gaming counterexample
- benchmark resource cost violates mobile budgets
- stronger practical evidence method changes the tradeoff
