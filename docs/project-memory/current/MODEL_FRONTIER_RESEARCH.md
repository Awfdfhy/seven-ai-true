# Seven AI — Model Frontier Research Snapshot

Date: 2026-09-14
Status: RESEARCH SNAPSHOT — not a permanent model ranking
Purpose: preserve the model-search findings that materially affect Seven Model Fabric and the Ultimate Polish campaign.

## Prime rule

Seven must never hard-code a model as “best in the world” from one leaderboard, a stale score, provider marketing, or a temporary free route.

A candidate becomes a Seven champion only after:

`identity/version proof → same-version independent benchmark evidence → access/free-proof → endpoint capability proof → Seven Evals → adversarial comparison → qualification lease`

Scores from different Artificial Analysis Intelligence Index revisions/scales must not be compared numerically.

## Seven decision

1. Kimi K3 is a strong candidate for the current deep-intelligence pool, not a permanent single-model dependency.
2. Seven should retain multiple qualified free/fallback endpoints and route by task, capability, latency, health, quota and verified outcome quality.
3. “Free” is a proof class, not a boolean. Distinguish durable free tier, development/trial endpoint, signup credits, temporary promotion, local/self-hosted, and paid access.
4. A model that disappears, becomes paid, becomes rate-limited beyond usefulness, changes revision, or loses qualification must automatically lose champion status.
5. The final claim “Seven beats X” must come from Seven end-to-end Evals, not by adding orchestration features to a base-model leaderboard score.

## Frontier target

The frontier watch target is dynamic:

> Find a model Seven can legally call programmatically at no monetary cost that exceeds the current Claude Opus/Fable frontier on the **same current independent index revision**, then verify it in Seven Evals.

Never encode a fixed score such as `51` as a permanent threshold. Re-resolve the target benchmark revision and competitor score at evaluation time.

## Integration consequences for Ultimate Polish

- Model Fabric must ingest benchmark revision, provider, model revision, free-proof class, terms freshness, rate-limit observations, capability claims and Seven-Eval receipts as separate evidence.
- Champion selection must use qualification leases with expiry.
- Provider marketing and benchmark scores cannot grant endpoint eligibility.
- Temporary free endpoints may be used as opportunistic capacity but require fallback before user-visible commitment.
- Seven’s “Unlimited Experience” means no arbitrary Seven-side quota. It does not mean pretending upstream provider limits do not exist.
- The final Model Polish should benchmark the qualified pool on reasoning, coding, research, tool use, vision/multimodal, long context, RPG/story, factuality, latency, cancellation and Android resource impact.
