# Seven Design Genome 1.0 - Candidate Portfolio

Status: PHASE_2_CANDIDATE_PORTFOLIO
Governance: Visual Intelligence V1.4 freeze

## Goal
Create a recognizable Seven visual DNA before polishing individual screens.

The Genome must make a new surface feel like Seven without requiring a logo in every corner, while remaining calm enough for long chat/research/coding sessions.

# Shared kernel across all candidates

## 1. Personality
Seven should read as:
- intelligent without looking clinical
- premium without looking ornamental
- fast without looking restless
- imaginative without becoming game-like outside World/RPG
- evidence-aware without becoming enterprise-dashboard gray
- distinctly Seven without borrowing another AI product's signature composition

## 2. Information hierarchy
Use three primary visual depths:
- Canvas: quiet background / reading field
- Surface: controls, grouped context, cards when grouping is useful
- Focus: current action/state/evidence requiring attention

Avoid card-on-card-on-card nesting. Prefer whitespace, rails, grouping and typography before adding containers.

## 3. Seven signature primitives
Candidate genomes may interpret these differently, but the portfolio tests a shared family of signatures:

### Orbit Thread
A thin path/arc/rail motif representing active cognitive flow or lineage. It appears sparingly in state/evidence/progress contexts, never as constant decoration.

### Seven Cut
A controlled diagonal or directional cut derived from the geometry of the numeral 7. It can influence icon terminals, selected-state marks, dividers or hero geometry without turning every component into a 7.

### Evidence Rail
A restrained line/edge treatment for citations, tool output, verification and provenance. It creates recognizable information structure and supports Seven's truth-first identity.

### Focus Halo
A subtle local emphasis around the active composer/control/state. It must remain cheaper and quieter than full-surface glows.

### State Node
A compact semantic marker used for Aurora/run state. Shape + label/icon carries meaning; color is secondary.

## 4. Shape grammar
- primary conversational surfaces: soft but not bubbly
- technical/evidence surfaces: slightly tighter geometry
- destructive/critical states: shape does not become playful
- pills reserved for compact toggles/status/chips, not every button
- nested radii follow an explicit hierarchy
- domain personality may modify local geometry only within bounded tokens

## 5. Typography grammar
Roles:
- Display / launch only
- Screen title
- Section title
- Body / conversation
- Evidence / source metadata
- Label / control
- Code / terminal / path
- Numeric/data emphasis

Arabic and Latin must feel equal in importance and rhythm. Avoid typography whose premium character exists only in Latin.

## 6. Color architecture
Color is layered:
1. neutral canvas/surfaces
2. persistent Seven brand anchor
3. Aurora semantic state
4. domain accent
5. critical semantic colors

Brand and Aurora are not the same thing. Aurora can change with runtime state while Seven remains visually identifiable.

Day/Night are related transformations:
- Day emphasizes clarity, air and crisp separation
- Night emphasizes depth, controlled luminance and reading comfort

Neither theme is a recolor filter of the other.

## 7. Motion grammar
Base motion character:
- quick acknowledgement
- smooth settle
- minimal overshoot
- no decorative bounce loops
- state transitions explain causality
- repeated interactions become quieter

Signature motion is reserved for launch, major workspace transitions and rare brand moments.

## 8. Domain personality

### Core
Quiet, conversational, generous reading field.

### Build
Denser, sharper hierarchy, stronger code/output separation, exact execution states.

### Research
Evidence rails, source hierarchy, comparison and uncertainty visibility.

### World / RPG
Atmospheric depth and richer narrative framing while retaining Seven controls, typography and semantic-state grammar.

## 9. Mobile rule
One-handed mobile interaction is the baseline composition. Desktop/tablet expansion adds space and simultaneous context rather than shrinking a desktop layout onto a phone.

# Candidate Genome Directions

## G-A: Orbital Precision
Character: calm, technical, luminous precision.
Signature: Orbit Thread + State Node + restrained diagonal Seven Cut.
Strength hypothesis: strongest all-purpose product identity with low fatigue and excellent coding/research fit.
Risk: could become too cool/technical if not balanced with warmth in Core and World.

## G-B: Celestial Duality
Character: stronger Day/Night personality with a common geometric core.
Signature: controlled solar/lunar field treatment around the same Seven mark; subtle orbit language.
Strength hypothesis: memorable identity and strong theme storytelling.
Risk: can become decorative or fantasy-coded if celestial motifs spread beyond brand moments.

## G-C: Evidence Lumina
Character: editorial clarity + computational state.
Signature: Evidence Rail, sharp typography hierarchy, Aurora light restricted to active information paths.
Strength hypothesis: unusually strong truth/research identity and very low clutter.
Risk: can feel too utilitarian unless the logo/motion supplies emotional signature.

## G-D: Folded Infinity
Character: geometric, compact, highly recognizable.
Signature: Seven Cut and loop/continuity geometry repeated subtly in icon terminals and selected-state geometry.
Strength hypothesis: strongest brand distinctiveness and tiny-size language.
Risk: too much geometric repetition could become gimmicky.

# Tournament strategy
Do not select a Genome from descriptions.

For each direction, build matched prototype surfaces:
- Core chat
- composer
- sidebar/workspace launcher
- coding surface
- research evidence surface
- RPG surface
- settings/permission dialog
- Day and Night
- Arabic and English

Then run the locked Visual Evaluation Constitution.

Hybrid candidates are allowed only after individual directions are understood. A hybrid must solve a documented weakness rather than merely combine favorite decorations.

# Initial hypothesis
Orbital Precision is the safest broad foundation, while Celestial Duality and Folded Infinity contain potentially stronger signature identity. Evidence Lumina is a strong simplifier/control candidate.

This is a hypothesis, not a winner.
