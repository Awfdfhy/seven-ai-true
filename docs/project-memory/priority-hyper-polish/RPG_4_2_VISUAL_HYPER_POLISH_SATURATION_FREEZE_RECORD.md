# Major accepted visual capabilities

## Persistent character visual identity
- IdentityVisualCore
- PresentationState
- VisibleConditionState
- FormRef / visual deltas
- concealment/visibility state
- temporal appearance reconstruction

## Living presentation
- contextual PresentationPolicy
- legal PresentationAffordances
- role/weather/event/world/cultural context
- character presentation preferences
- signature visual cues
- no magical unavailable wardrobe
- near-zero background presentation compute

## Perspective / disguise / recognition
- visible cues projected through Perception
- observer-local RecognitionHypothesis
- apparent identity separate from true identity
- observer-dependent recognition
- misidentification and later correction
- visual clues can feed Investigation without becoming automatic truth

## Real Works visual fidelity
- CanonVisualBinding by continuity/adaptation/time/form/outfit
- anime/manga/game variants remain separate
- source evidence role separate from generation-reference role
- CANON_GAP preserved
- branch visual choices never relabeled official canon

## References / anchors
- ReferenceArtifact ingestion does not directly update truth
- conflict/variant classification
- scoped field/variant approval
- semantic multi-view anchor roles
- VisualCoverageMap
- anchor validity/invalidation
- frozen AnchorEligibilitySnapshot per render attempt

## Images / storyboards / video
- provider-neutral VisualSceneContract / VisualRenderContract
- per-character VisualRoleBinding
- state-first continuity hierarchy
- bounded relevant anchor selection
- long-video segment re-anchoring
- prior generated frames remain weak hints
- GenerationManifest + artifact metadata
- independent multi-axis visual verification

## Async / tool integrity
- generation requests bind world/scene/visual base versions
- returned media classified CURRENT_VALID / HISTORICAL_VALID / STALE_PRESENTATION / STATE_CONTRADICTED / BRANCH_MISMATCH
- Tool Fabric / Side-Effect Ledger owns dispatch certainty and retry semantics
- cancellation does not fabricate remote-stop certainty
- provider/model revision and capability drift are explicit
- parallel candidates cannot race to mutate world state

## Mobile / graceful degradation
- no mandatory bundled image/video model
- no always-on generator sessions
- no default dense embedding requirement
- compact typed visual state
- lazy reference/anchor metadata
- media cache eviction
- Lite mode remains full RPG with text/state visual continuity
- media generation remains optional

# Research alignment

The architecture intentionally captures generalizable lessons from current 2025–2026 consistent-generation research:
- identity is broader than a face cue
- clothing/details can drift separately
- multi-view and semantic content anchors help long-range consistency
- multi-character generation benefits from explicit role/layout binding
- strong identity constraints must not destroy motion/semantic freedom
- long video benefits from re-anchoring rather than recursive generated-frame authority

Seven adopts these as provider-neutral architectural requirements rather than hardcoding one research model.
