# Seven Polishing V4 — Self-Polish Round 03

Verdict: MATERIAL_IMPROVEMENT_FOUND
Saturation counter: 0/2

## Review lens
Round 03 evaluated whether V4 can scale from one subsystem to the entire Seven program without creating process bloat, stale documentation or false confidence.

## Material improvements

1. Gate tailoring matrix: mark each gate REQUIRED, CONDITIONAL or NOT_APPLICABLE with rationale so rigor does not become meaningless ceremony.
2. Artifact deduplication: V4 requires information, not dozens of physical files. One canonical record may satisfy multiple views when ownership remains explicit.
3. Campaign checkpoint: long campaigns preserve candidate identity, open uncertainty, saturation counter, latest material improvement, unresolved critical items and next gate.
4. Evidence-to-decision lineage: accepted decisions link to scenarios, evidence, alternatives and regression tests.
5. Incremental revalidation: a reopen trigger computes blast radius. Unaffected decisions may retain still-fresh evidence; affected decisions and dependencies re-enter required gates.
6. Protocol health diagnostics: track critical decisions with tests, unresolved uncertainty, stale evidence and regression coverage. These diagnostics are not a universal score.
7. Freeze-debt prohibition: mandatory unfinished architecture work cannot be hidden under a generic deferred label. Deferred items must be implementation work, optional enhancement or bounded noncritical uncertainty.
8. Search diversity: where external evidence matters, seek multiple evidence classes when available, such as primary research/standards, platform engineering, production/open-source evidence and product/user evidence. Missing diversity remains explicit.

## Result
Round 03 found material improvements, so V4 remains 0/2 and requires reconciliation before final independent reviews.
