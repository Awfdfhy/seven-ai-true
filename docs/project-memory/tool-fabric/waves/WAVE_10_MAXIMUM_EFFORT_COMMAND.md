## SEVEN MAXIMUM EFFORT — TOOL FABRIC 2.0 / WAVE 10

Goal: discover the strongest practical research/evidence capabilities that let Seven perform deep, source-grounded research beyond generic web search while keeping provider dependencies replaceable and avoiding false authority from citation count, popularity or model synthesis.

Search current primary documentation for scholarly/open metadata APIs, repositories, citation/identifier standards, web archive/source snapshot tools, literature retrieval, deduplication, citation parsing and evidence-management primitives. Prefer open/free/self-hostable sources where useful, but record quotas/terms and never imply that free today means permanently unlimited.

Research at minimum:
- DOI / bibliographic metadata resolution
- scholarly graph/search APIs
- preprint repositories
- open-access discovery
- citation/reference graph expansion
- retraction/correction signals
- source identity and canonical identifiers
- metadata deduplication / record linkage
- article/document text extraction boundaries
- evidence chunk/source anchoring
- source snapshots/hashes
- source freshness/update detection
- contradiction/evidence clustering
- primary-vs-secondary source classification
- technical documentation/version source discovery
- structured web archives only where legal/practical
- dataset/code/software-paper linking
- research query decomposition
- source diversity and independence
- evidence packs usable by Truth Fabric
- citation rendering/export
- provenance standards already discovered in Wave 04

For every candidate determine:
- data/source coverage
- authoritative scope and what it does NOT prove
- API/free/rate-limit/auth model
- freshness/update behavior
- license/terms for metadata/text
- stable identifiers
- Android/network cost
- self-host feasibility where relevant
- response schemas and pagination
- duplicate/merged-record behavior
- retractions/corrections support
- whether full text is actually available or metadata only
- privacy implications of submitted queries
- integration burden and maintenance risk
- overlap with SearchBroker/SourceLedger

Rules:
- citation count is not truth or quality score.
- search rank is not evidence authority.
- metadata records are claims about works and must preserve provider provenance.
- DOI identifies an object/record; it does not certify correctness.
- abstracts/snippets are not substitutes for full-text claims when claim-level verification requires the source.
- retraction/correction state must be checked where relevant and available.
- one underlying paper mirrored by multiple providers is one evidential source, not independent corroboration.
- deduplicate by canonical identifiers plus metadata fingerprinting, but preserve provider-specific records/lineage.
- respect access/licensing; do not design Seven around bypassing paywalls or access controls.
- evidence extraction retains page/section/paragraph/time/source anchors where available.
- research synthesis cannot gain authority over primary evidence merely through repetition.
- provider-specific research services remain adapters behind Seven-owned contracts.

Output:
1. candidate/provider/standard registry
2. Research Evidence Plane architecture
3. canonical research tool contracts
4. source identity/dedup model
5. citation graph expansion strategy
6. source quality/retraction/correction strategy
7. evidence pack schema
8. query/depth/budget strategy
9. Android/network/cache strategy
10. rejected/limited approaches
11. Deep Polish queue

Preserve all material findings, evidence, uncertainty and negative results in GitHub. No production integration during discovery. Do not modify `seven_ai-final.html`, delete files or merge protected branches.
