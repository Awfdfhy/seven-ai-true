Status: **ARCHITECTURE FROZEN FOR ULTIMATE POLISH CAMPAIGN**

## Frozen target

**Seven Retrieval Fabric 3.0 — Adaptive Evidence Discovery Mesh**

## Prime law

> Retrieval finds candidates; it does not manufacture evidence, truth, authority, freshness, or completion.

## Frozen decisions

1. Search observations and snippets are discovery signals, not canonical evidence.
2. `RetrievalNeed` classifies the need before choosing search strategy.
3. Exact/keyed and lexical/BM25 paths are permanent cheap baselines.
4. Dense retrieval, hybrid fusion, query expansion and reranking are conditional, evaluated capabilities.
5. Query rewriting must preserve lineage to the original need and cannot silently change the researched claim.
6. Candidate discovery is separated from source fetch/extraction.
7. Durable evidence requires source identity/version and exact extract locators.
8. Deduplication includes source/content/syndication clustering while preserving provenance.
9. Ranking scores never grant epistemic authority.
10. Freshness remains claim-scoped and is judged by Research/Epistemic contracts.
11. Follow-up search is bounded by CoverageContract, marginal evidence gain and compute budget.
12. BrowserActionBroker is an escalation layer, not the default retrieval path.
13. Provider bindings have independent health, capability, privacy and fallback state.
14. Retrieval caches are optimizations and never prove source immutability.
15. Arabic and mixed Arabic/English retrieval are first-class eval strata.
16. Lite/mobile operation cannot require embeddings, a vector DB or heavy reranker.
17. Large fetched content is artifactized; Context receives bounded source-bound views.
18. Untrusted result/page content remains data, never privileged instruction authority.
19. Cancellation and backpressure propagate through parallel search/fetch work.
20. Every material run produces a compact `RetrievalRunManifest` for reproducibility and diagnostics.

## Ownership boundary

Research owns claim gaps/coverage/synthesis. Retrieval owns discovery/fetch strategy. Knowledge owns durable local sources/indexes. Epistemic owns truth/authority/conflicts. Context owns prompt inclusion. Adaptive Compute owns depth/concurrency. Tool Fabric/Security own execution and authorization.

## Required eval families

Exact lookup, lexical win, semantic paraphrase, hybrid need, multi-turn rewrite, stale/fresh queries, duplicate floods, contradictions, Arabic/mixed language, provider failure, untrusted result text, Lite without vectors, browser escalation, cancellation, early stop on coverage, explicit no-answer/gap.
