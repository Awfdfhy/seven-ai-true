## Frozen target

**Seven World Linguistic Engine 3.0 — Evidence-Grounded Naming Grammar**

## Prime law

> A title is a typed linguistic artifact of a world, medium and moment. Seven generates from an explicit naming grammar and evidence profile, not from a generic naming prompt or copied title list.

## Frozen decisions

1. Naming taxonomy is world/medium-specific rather than one universal list.
2. Every name carries explicit status: official, official-localized, user-defined, Seven-generated, in-world generated, placeholder or unknown.
3. Generated names are never silently presented as official canon.
4. `WorldLanguageProfile` is a source-bound derived profile of linguistic tendencies.
5. `NamingGrammar` owns morphology, syntax, punctuation, numbering and domain rules.
6. Deterministic rules run before model-assisted generation when sufficient.
7. Naming requests bind to authoritative subject/event/world context; the title engine cannot invent canon facts to justify a title.
8. Hard grammar/status/collision constraints filter before soft ranking.
9. Official names and source-supported localizations retain identity/source lineage.
10. New generated content uses abstract style constraints rather than copying/remixing copyrighted title lists.
11. Collision detection covers official names, generated names, aliases and localizations.
12. Reproducible mode binds grammar/profile/request/seed/model revision into a `NamingManifest`.
13. Localization variants link to one `TitleIdentity` and preserve official-vs-generated status.
14. Arabic/RTL rules are structural, not a post-processing patch.
15. RPG supplies world context; Canon supplies official identities; Titles owns naming only.
16. Branch-generated titles remain branch-scoped.
17. Profiles/grammars are compact and model generation is lazy, keeping mobile cost low.

## Canonical objects

`NamingDomain`, `TitleKind`, `WorldLanguageProfile`, `NamingGrammar`, `NamingConstraintSet`, `NamingEvidenceRef`, `NamingRequest`, `NamingCandidate`, `NamingDecision`, `TitleIdentity`, `LocalizationVariant`, `CollisionRecord`, `NamingManifest`.

## Required eval families

Status separation, type-specific grammars, deterministic replay/variation, official and generated collisions, branch scope, localization, Arabic/RTL, UI length, spoiler-safe naming, semantic fit, repetition fatigue, profile versioning and novel/non-copy candidate checks.
