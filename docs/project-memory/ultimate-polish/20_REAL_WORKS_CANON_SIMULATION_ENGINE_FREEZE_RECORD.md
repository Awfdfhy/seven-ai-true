## Frozen target

**Seven Canon Simulation Engine 3.0 — Source-Locked Branch-Aware Living Canon Graph**

## Prime law

> Canon is never model memory. Canon is a source-bound, continuity-scoped graph of supported commitments. Missing coverage becomes `CANON_GAP`; incompatible player divergence becomes an explicit branch.

## Frozen decisions

1. Canon support requires source/version/evidence lineage; model recall cannot create canon evidence.
2. Canon state classes distinguish supported canon, gaps, conflicts, adaptation variants, supported derivations and explicit divergence.
3. Continuities/adaptations are explicit and do not silently leak facts into one another.
4. Chronology is a partially ordered event graph where needed, not a forced single sequence.
5. Character knowledge is source/event/time scoped and future knowledge is blocked.
6. `CanonAnchor` is a structured protected obligation, not just a numeric weight.
7. A `CanonCoverageContract` must be satisfied before claiming a scene is canon-preserving.
8. Missing critical coverage yields `CANON_GAP`, not invented certainty.
9. Player insertion searches for causal slack while preserving player agency.
10. Player choices are never overridden merely to keep canon intact.
11. Real incompatible changes produce a `DivergenceEvent` and explicit `CanonBranch`.
12. Branch consequences are tracked structurally through invalidated/reachable dependencies rather than one authoritative `canonDebt` scalar.
13. Plausible inference remains `SUPPORTED_DERIVATION`, not official canon.
14. Source conflicts are preserved and resolved by continuity/evidence rules rather than averaging.
15. Spoiler policy is distinct from NPC in-world knowledge horizons.
16. Canon facts/graphs/locators are sufficient; long copyrighted works need not be copied into prompts or storage.
17. Canon Engine supplies constraints to RPG Engine; RPG Engine owns generic world state and causality.
18. Hot context contains only the active canon subgraph and source handles needed for the current scene.
