# Seven AI — Capability 18 Vision Freeze Record

Status: **ARCHITECTURE FROZEN FOR ULTIMATE POLISH CAMPAIGN**
Implementation: **Deferred / partial vision foundations remain**

## Frozen target

**Seven Vision Fabric 3.0 — Provenance-Bound Selective Perception Plane**

## Prime law

> Vision observes pixels and proposes structured observations. It does not gain action authority, world truth, or file truth merely because a model described an image confidently.

## Frozen decisions

1. Every image/page/frame is bound to a `VisualVersion` and exact origin.
2. Crops/resizes/redactions are derived transformations with lineage.
3. Perception uses a staged cheap-to-expensive ladder.
4. OCR text is a derived artifact, not original source truth.
5. Document layout, reading order and region structure remain explicit derived artifacts.
6. Semantic observations bind to exact source regions and model/method identity.
7. VLM prose is not the canonical observation store.
8. Screenshot coordinates are ephemeral proposals and require current-frame validation.
9. Vision has no click/type/upload/send authority; actions are separate secured tool contracts.
10. Accessibility/DOM structure can complement pixels but remains separately sourced and may disagree.
11. Video/screen perception uses adaptive keyframes/deltas rather than constant high-rate analysis.
12. Precise chart/document values remain unresolved when the pixels/evidence cannot support them.
13. Remote perception can minimize/crop data before dispatch according to privacy policy.
14. Model Fabric chooses specialized perception routes; no universal vision model is assumed.
15. Mobile baseline lazy-loads heavy vision/OCR components and reuses valid derivatives.
16. No ambient background camera/screen analysis exists merely because Vision is installed.

## Canonical objects

`VisualSource`, `VisualVersion`, `VisualFrame`, `VisualRegion`, `OCRArtifact`, `LayoutArtifact`, `VisualObservation`, `GroundedObservationSet`, `PerceptionRequest`, `PerceptionPlan`, `PerceptionManifest`, `FrameDelta`, `VisualEvidenceRef`.

## Required eval families

Arabic/scanned OCR, mixed UI, tables/charts, diagrams, tiny text, stale coordinates, unexpected windows, duplicate frames, privacy minimization, OCR/VLM disagreement, source-region reconstruction, multipage/orientation, Lite/cancellation/thermal downgrade and the no-action-authority invariant.

## Implementation path

`VF-P0` contracts → `P1` OCR → `P2` layout/regions → `P3` grounded VLM observations → `P4` documents/charts → `P5` UI/frame validation → `P6` temporal sampling → `P7` privacy/minimization → `P8` evidence bridge → `P9` resources/observability → `P10` evals.

No implementation completion is claimed by this freeze.
