# Canon and Memory Contract

Keep these categories distinct:
1. Canon facts approved as authoritative.
2. Confirmed event history with time and provenance.
3. Current world state derived from accepted domain events.
4. Character-specific knowledge and source of acquisition.
5. Character beliefs, uncertainty, and mistaken conclusions.
6. Rumors and hearsay with source/confidence.
7. Summaries that reference the evidence they compress.
8. AI-generated proposals awaiting validation.

Retrieval must be scoped by world, character, time, permissions, relevance, and provenance. Unknown facts must remain unknown; model confidence is not proof. A summary cannot silently replace the event log. An idea suggested by AI is not canon until an explicit rule/player-authority process accepts it. Tests must attempt cross-world leakage and knowledge leakage between characters.
