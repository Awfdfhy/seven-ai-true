# Pattern Library — Security & Privacy

Status: ACTIVE KNOWLEDGE PACK

## Data classification

Separate public UI state, personal content, credentials/secrets, device identifiers, repository authority and model/tool permissions.

## Mobile baseline

Use OWASP MASVS categories: storage, crypto, auth, network, platform, code, resilience and privacy. Keep secrets out of logs and model-visible context.

## Self-dev

Builder cannot alter evaluator/protected constitution to win. Repository mutation is scoped, SHA-bound, reviewable and rollback-capable.

## Telemetry

Collect the minimum. Content capture is opt-in. Redact tokens and sensitive file/user data.
