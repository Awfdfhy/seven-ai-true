# Pattern Library — Arabic, RTL & Bidirectional Content

Status: ACTIVE KNOWLEDGE PACK

## Principles

Translate intent, not words. Keep code, URLs, numbers and citations readable as directional islands. Mirror navigation direction where semantic; do not mirror universal symbols unnecessarily.

## Layout

RTL affects alignment, ordering, sheet/sidebar edge and directional motion. Text direction may differ within the same message.

## Testing corpus

Arabic-only; English-only; Arabic with English product/model names; code block; URL; numbered list; citations; emoji; punctuation; long unbroken tokens.

## Visual checks

Glyph clipping, line height, truncation, icon direction, focus order, composer cursor behavior, source chips and table/code overflow.
