# Pattern Library — AI Product Benchmarking

Status: ACTIVE KNOWLEDGE PACK

## Rule

Study products to learn principles, not copy branding/assets/pixels.

## Compare

First-action clarity; composer density; tool discovery; model selection; response readability; sources; files; history; loading/error states; mobile navigation; accessibility; perceived speed.

## Benchmark set

ChatGPT: conversation-first hierarchy/progressive tool disclosure. Gemini: multimodal/expressive response organization. Perplexity: query/source/research integration. Copilot: task-aware connected workflows. Poe: model abundance and the information-architecture challenge it creates.
