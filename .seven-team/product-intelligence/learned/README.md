# Learned Product Intelligence

This directory is the cumulative team-owned learning layer.

Agents may add evidence-backed Markdown/JSON entries here only when the Manager explicitly assigns product-intelligence curation. Entries must:
- cite the public/reference source URL or repository evidence;
- include observation date;
- separate observation from inference;
- name the Seven surface affected;
- propose a testable lesson;
- never include secrets or proprietary copied assets;
- never overwrite the canonical rubric without Manager review.

Suggested naming:
YYYY-MM-DD-product-topic.md

The canonical knowledge base is periodically distilled from these learned entries.
