## Operating rule

Every research/explore/polish cycle must:
1. read this index;
2. read the rubric;
3. inspect only the knowledge/reference sections relevant to the assigned subsystem;
4. distinguish observed evidence from inference;
5. never copy a competitor pixel-for-pixel;
6. use references to judge hierarchy, clarity, friction, density, feedback, motion, responsiveness and cohesion;
7. preserve Seven identity.

A build is not a quality release merely because tests pass. Product quality requires functional correctness + interaction quality + visual coherence + understandable information architecture + trustworthy feedback + Android/RTL quality.
