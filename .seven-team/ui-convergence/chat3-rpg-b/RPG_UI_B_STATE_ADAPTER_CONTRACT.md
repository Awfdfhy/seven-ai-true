# RPG_UI_B_STATE_ADAPTER_CONTRACT

Purpose: define the pure, read-only boundary between RPG state and Chat 3 visual systems. This is not a new gameplay feature.

## Input
Canonical source: `SevenRpgState.createState(...)` / current RPG session snapshot.

## Output view models
All adapters MUST:
- be pure
- never mutate RPG state
- omit absent data instead of synthesizing values
- preserve explicit labels/identifiers
- expose a `sourcePresent` flag for optional sections
- never convert unknown numeric scales into percentages

### AbilityVM
```js
{
  id,
  name,
  owners: [],
  tags: [],
  costEntries: [{label,value}],
  limitations: [],
  weaknesses: [],
  cooldown: {
    turns: number,
    lastUsedTurn: number|null,
    ready: boolean|null,
    remainingTurns: number|null
  },
  forbidden: boolean,
  powerScale: number|null
}
```
Rules:
- `ready` is null if current turn is not known.
- `powerScale` is a labeled raw value only; never render as damage unless runtime semantics say damage.

### ItemVM
```js
{
  id,
  name,
  quantity,
  ownerId,
  locationId,
  equippedBy,
  consumable,
  tags: [],
  stateEntries: [{label,value}]
}
```
Rules:
- no rarity unless explicit tag/state contract says rarity.
- no recommendation arrow.
- no derived attack/defense comparison.

### FactionVM
```js
{
  id,
  name,
  goals: [],
  leaders: [],
  members: [],
  resources: [{label,value}],
  alliances: [],
  enemies: [],
  territory: [],
  reputation: [{label,value}],
  updatedTurn
}
```

### WorldPulseVM
```js
{
  currentLocationId: string|null,
  activeEvents: [],
  wars: [],
  politics: [],
  economy: [],
  resources: [],
  timeline: {
    tick,
    dateLabel,
    recentEvents: []
  }
}
```
Only serialize object fields that can be represented safely as short label/value rows. Nested or opaque structures go to details, never primary HUD.

### BattleContextVM
```js
{
  active: boolean,
  sceneId: string|null,
  locationId: string|null,
  conflicts: [],
  participantIds: [],
  abilities: AbilityVM[],
  turnOrder: null,
  hp: null,
  mp: null
}
```
Current state contract does not provide canonical `turnOrder`, HP or MP. Keep these explicit nulls to prevent UI code from guessing.

## Empty-state behavior
- no abilities => hide Skills section
- no items => hide Inventory section
- no factions/world strategic data => hide Kingdom section
- no active events => no World Pulse badge
- no location => show no fabricated “Unknown Region” card; omit location block

## Security/integrity
Adapters are read-only projections. No button generated by these adapters may dispatch RPG mutations until the owning runtime exposes an approved command contract.
