# R06 — INVENTORY / PROGRESSION RESEARCH

Research-first lane. No production writes.

Key findings:
- Genshin mobile is useful for touch density/category navigation, but its economy/gacha chrome is explicitly rejected.
- Monster Hunter is useful for equipment/crafting detail layering, but dense console tables must be simplified.
- Diablo demonstrates inventory/equipment identity and skill hierarchy, but phone grids and icon saturation must not be copied.
- Witcher demonstrates loot/map/store separation and progressive details.
- Seven's current item schema supports identity, ownership, equipped state, quantity, consumable/state/tags; it does not guarantee rarity/stat comparisons.
- Recommended inventory model: list or 2-column hybrid -> bottom detail sheet; comparison only from explicit comparable state.
