# Typography System

Use seven roles only: Display, Title, Heading, Body, Small, Caption, Mono. Body copy is the default; headings indicate information hierarchy, not decoration. Arabic must not inherit Latin negative tracking. Mixed Arabic/English model names and filenames use `unicode-bidi: plaintext` or isolation on the mixed-content leaf, not on entire containers. Code remains LTR/isolate regardless of page direction. Text containers must survive 200% zoom without fixed-height clipping.
