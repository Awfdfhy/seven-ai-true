# Accessibility Guide

Target WCAG 2.2 AA for shipped shared UI. Focus must be visible, not hidden by sticky/overlay UI, and distinguishable from unfocused state. Controls need accessible names; errors are associated with fields and are not color-only; disabled state remains readable; semantic headings follow document hierarchy. Default touch targets are 44px. Support reduced motion, keyboard navigation, focus restoration after dialogs, and practical 200% text scaling with no horizontal document overflow.
