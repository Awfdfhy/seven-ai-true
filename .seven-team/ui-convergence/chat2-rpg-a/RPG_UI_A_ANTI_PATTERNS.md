# RPG UI A Anti-Patterns

1. **Purple chat syndrome** — ordinary chat + fantasy accent + "RPG" badge.
2. **Every-message card** — destroys reading rhythm and makes long narration exhausting.
3. **Permanent HUD** — location/time/chapter/cast always consuming vertical space.
4. **Portrait wallpaper** — large art on every turn; poor at 320px.
5. **Spreadsheet character sheet** — every field presented as label/value grid.
6. **Single heart meter** — collapses trust, respect, fear, suspicion, rivalry and loyalty into romance.
7. **False precision** — exposing raw 0.42 trust in primary UI.
8. **Spoiler graph** — showing hidden relationships, beliefs or unknown actors.
9. **Omniscient knowledge panel** — revealing global truth while user is in character perspective.
10. **Badge confetti** — Narrator/Character/System/Memory badges on every message.
11. **Hard-coded left/right** — breaks Arabic RTL.
12. **Desktop graph squeezed onto mobile** — unreadable nodes/edges.
13. **Codex skeuomorphism overload** — parchment textures, tiny serif type, fake book chrome.
14. **Everything is a tab** — fragmented archive navigation.
15. **Menu-first RPG** — user sees control panel before story.
16. **Debug enum UI** — raw engine states as primary labels.
17. **Copy/action permanence** — toolbars visible on every story turn.
18. **Color-only semantics** — inaccessible relationship/canon distinctions.
19. **Fake mood** — synthesizing mood labels not supplied by runtime.
20. **Fake world HUD** — weather/HP/time/location where data is absent.
21. **Novelty over discoverability** — experimental gestures with no conventional fallback.
22. **Unbounded timeline** — thousands of equal-weight events without summarization/focus.
23. **Character identity overload** — name + role + age + mood + relationship + faction + status every turn.
24. **Unverified causal copy** — "Trust rose because…" when event provenance does not support it.
25. **Global-token fork** — RPG defining a second design system instead of semantic layers atop Seven tokens.
