## Method
The database treats one **screen/surface pattern** as one reference. Multiple surfaces from the same title are intentionally separate because Seven needs pattern-level comparison, not a list of games.

Major source anchors were manually checked for Persona 5 Royal, Baldur's Gate 3, Disco Elysium, Fire Emblem: Three Houses, Genshin Impact, Mass Effect, Dragon Age: Inquisition, The Witcher 3, Pentiment and Citizen Sleeper. Remaining links are research locators or storefront/reference pages and must be visually verified before any literal layout decision.

## Scoring
Scores are 1–5. `suitability_for_seven` rewards patterns that can preserve chat simplicity while exposing persistent narrative state through progressive disclosure.

## Hard rule
No visual reference authorizes a feature. Implementation is gated by Seven runtime data availability.
