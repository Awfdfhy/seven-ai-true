# Seven Domain Campaign

This campaign forces Seven's continuous team to research, plan, improve and verify each major product/runtime subsystem separately.

- `domains.json`: canonical domain inventory, owners, priorities and research-source targets.
- `RESEARCH_STANDARD.md`: evidence and output contract.
- `generated/latest.md`: latest Manager-generated domain roadmaps (written by Superloop).
- `generated/latest-audit.json`: machine audit of source/coverage sufficiency.
- `generated/history/`: per-cycle roadmap history.

The campaign does not treat internet research as runtime proof. Research proposes architecture; Seven's exact tests/Reality Lab/Constitution decide whether implementation is accepted.
