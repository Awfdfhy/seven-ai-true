## 2. Bugs Found (Sorted by Severity)

### A10-001 — BLOCKER — VERIFIED
**Surface**: `release/control-bridge.js:1` — `SevenBridge` boot sequence  
**Symptom**: Bridge throws `Error('SevenControl runtime required')` if `SevenControl` not ready, but `safeBoot()` only catches sync errors; async initialization race leaves `state.ready=false` permanently.  
**Root Cause**: `boot()` called in `DOMContentLoaded` handler (line 152) but `SevenControl` may initialize later via lazy-loaded workspace scripts. No retry/backoff.  
**Reproduction**: Load app with slow network; `SevenControl` loads after `DOMContentLoaded` → `safeBoot()` fails silently, `state.error` set, `state.ready` stays false.  
**Fix Direction**: Add polling retry in `safeBoot()` with max attempts; expose `SevenBridge.retryBoot()` for manual recovery.  
**Regression Test**: Simulate delayed `SevenControl` load (100ms+ after `DOMContentLoaded`); assert `state.ready===true` within 2s.

### A10-002 — CRITICAL — STRONG
**Surface**: `release/attachment-runtime.js:24` — `renderSelection()` uses `strip.innerHTML=''` then appends chips  
**Symptom**: XSS via file `name` property — `label.textContent=item.name` is safe, but `chip.title=item.name+' · '+humanBytes(item.size)` uses `title` attribute (safe), however `chip.dataset.kind=item.category` and `GLYPH[item.category]||GLYPH.other` — if `category` returns attacker-controlled string, `GLYPH` lookup returns `undefined`, `icon.textContent=undefined` → no XSS. **But**: `humanBytes()` not shown; if it uses `innerHTML` anywhere, vector exists.  
**Root Cause**: Trusting `File.name`/`File.type` from `input.files` without sanitization; `category()` function (line 23) derives from MIME type — MIME sniffing can be spoofed.  
**Reproduction**: Create file named `<img src=x onerror=alert(1)>.pdf` with MIME `application/pdf`; attach → inspect chip `title` (safe) but check if any code path uses `innerHTML` with `item.name`.  
**Fix Direction**: Sanitize `item.name` for any HTML context; use `textContent` exclusively; validate `category` against allowlist.  
**Regression Test**: Attach file with HTML-in-name; assert no script execution, DOM contains only text nodes.

### A10-003 — CRITICAL — NEEDS_RUNTIME_TEST
**Surface**: `release/build-release.cjs:146-147` — Workspace concatenation order  
**Symptom**: `workspaceSource` reads directory with `fs.readdirSync().sort()` — lexical sort, not dependency order. `hub.js` must load before `research.js`/`rpg.js`/`coding.js` (they reference `SevenWorkspaces` from hub).  
**Root Cause**: `sort()` gives `['coding.js','generated-ui.js','hub.js','research.js','rpg.js',...]` — `hub.js` loads **after** dependents. Browser script execution order follows HTML order; `intelligence.js` loads first (line 154), then workspace scripts appended later (line 164-166) but **order not guaranteed**.  
**Reproduction**: Build release; load in browser; check console for `SevenWorkspaces is undefined` in `research.js`/`rpg.js` init.  
**Fix Direction**: Define explicit dependency graph in `build-release.cjs`; emit workspace scripts in topological order.  
**Regression Test**: Build → parse output HTML → assert `hub.js` script tag precedes all other workspace scripts.

### A10-004 — HIGH — VERIFIED
**Surface**: `release/beta-ui-runtime.js:36` — `installStopFix()` patches `r.stopGeneration`

**Reproduction**: Click stop button during generation; observe `ReferenceError: stopRequested is not defined` in console.  
**Fix Direction**: Declare `let stopRequested=false`; pass `activeAbortController` via closure or module export.  
**Regression Test**: Unit test `installStopFix()` with mocked `r.stopGeneration`; click stop; assert no ReferenceError.

### A10-005 — HIGH — VERIFIED
**Surface**: `release/beta-ui-runtime.js:39` — `installMessageArrival()` MutationObserver  
**Symptom**: Observer never disconnected on teardown; `S.messageObserver` accumulates if `installMessageArrival()` called multiple times (e.g., workspace switch).  
**Root Cause**: Line 40 creates new observer but only disconnects previous if `S.messageObserver` exists — but `S.messageObserver` is set **after** disconnect, so first call works, second call disconnects first, but third call disconnects second... wait, logic is correct. **However**: `arrivalNodes()` and `animateArrival()` not defined in provided snippet — likely global leak from `seven_ai-final.html`. If those functions removed/renamed, observer callback throws silently.  
**Reproduction**: Switch workspaces 3×; inspect `S.messageObserver` count; trigger message insert; check for errors.  
**Fix Direction**: Wrap callback in try/catch; expose `cleanupMessageArrival()` for workspace unload.  
**Regression Test**: Call `installMessageArrival()` 5×; insert message; assert single animation, no errors.

### A10-006 — HIGH — STRONG
**Surface**: `release/control-runtime.js:12` — `DEFAULT_SHARES` sum = 1.0 but `compileContext` uses `reserveTokens`  
**Symptom**: `reserveTokens` subtracted from `maxTokens` **after** share calculation → actual allocation exceeds budget when `reserveTokens > 0`.  
**Root Cause**: `buildTaskContext()` (control-bridge.js:110) passes `reserveTokens` to `compileContext`, but shares computed on full `budget` (line 112: `budget=Number(maxTokens)||...`). If `reserveTokens=2000`, `maxTokens=16000`, shares sum to 16000 but only 14000 available.  
**Reproduction**: Call `buildTaskContext({maxTokens:16000,reserveTokens:2000,...})`; inspect returned context `totalTokens` > 14000.  
**Fix Direction**: Compute shares on `budget - reserveTokens`; ensure `reserveTokens < budget`.  
**Regression Test**: `buildTaskContext({maxTokens:10000,reserveTokens:3000})` → assert sum of allocated tokens ≤ 7000.

### A10-007 — HIGH — NEEDS_RUNTIME_TEST
**Surface**: `release/beta-ui-runtime.js:17-21` — Theme auto-switch timer  
**Symptom**: `a()` sets `setTimeout` to switch at 6:00/18:00 but **does not clear** if user manually changes theme via `p(x)` before timer fires. Two timers can run concurrently.  
**Root Cause**: `p(x)` calls `a()` which sets new timer but `S.themeTimer` only cleared at start of `a()` — if `p(x)` called during `setTimeout` callback execution, race. Also `clearTimeout(S.themeTimer)` at line 20 but `S.themeTimer=0` after — if timer already fired, `clearTimeout(0)` no-op but new timer set.  
**Reproduction**: Set theme=auto at 17:59; at 18:00 manually switch to day; observe double-switch or flicker at 18:00+250ms.  
**Fix Direction**: Use `AbortController` or single timer with `Date.now()` check; cancel on any manual override.  
**Regression Test**: Mock `Date` at 17:59; set auto; advance to 18:00; manual switch; advance 300ms; assert single theme value.

### A10-008 — MEDIUM — VERIFIED
**Surface**: `release/beta-ui-runtime.js:25` — `H()` lazy-loads `hub.js`  
**Symptom**: `J` flag prevents double-load but **not** reset on error — `s.onerror=()=>J=0` resets, but if `hub.js` loads but `SevenWorkspaces.openLauncher` throws, `J=1` permanently, launcher broken until reload.  
**Root Cause**: `J` only reset on script load error, not on runtime error in `onload` callback.  
**Reproduction**: Corrupt `hub.js` (syntax error); click status button → `J=1`; fix `hub.js`; click again → nothing happens.  
**Fix Direction**: Wrap `onload` in try/catch; reset `J=0` on any error.  
**Regression Test**: Load broken `hub.js`; click launcher; fix script; click again; assert launcher opens.

### A10-009 — MEDIUM — STRONG
**Surface**: `release/attachment-runtime.js:27` — `build()` attaches `onclick` to `attach` button **every call**  
**Symptom**: If `build()` called multiple times (e.g., workspace re-entry), multiple click handlers accumulate → menu toggles multiple times per click.  
**Root Cause**: No guard `if (attach.dataset.sevenAttachBound) return` — only `input` has guard (line 50).  
**Reproduction**: Call `build()` twice; click attach button; menu opens/closes twice.  
**Fix Direction**: Add guard on `attach` element; use `addEventListener` with `{once:false}` but check existing.  
**Regression Test**: Call `build()` 3×; click attach; assert `S.open` toggles once.

### A10-010 — MEDIUM — VERIFIED
**Surface**: `release/canon-simulator.js:149-154` — Branching logic  
**Symptom**: `mustBranch` true if `rigid || next.canonDebt>=1 || meta.forceBranch===true` — but `meta.forceBranch` checked with `===true` (strict), while `meta.forceBranch` could be truthy string `"true"` from JSON.  
**Root Cause**: JSON deserialization yields string `"true"` not boolean; strict equality fails.  
**Reproduction**: Pass `meta: {forceBranch: "true"}`; simulate rigid anchor; assert branch not created.  
**Fix Direction**: Use `meta.forceBranch==true` or `Boolean(meta.forceBranch)`.  
**Regression Test**: `engine.advance({..., meta:{forceBranch:"true"}})` → assert `session.branchOrigin` set.

### A10-011 — MEDIUM — NEEDS_RUNTIME_TEST
**Surface**: `release/brand/runtime.js:1` — Logo swap on theme change  
**Symptom**: `s()` queries `.app-icon,.empty-logo` and sets `src` — but if elements not yet in DOM (lazy workspace), logo not updated. `visibilitychange` handler re-runs but only if `document.hidden` false.  
**Root Cause**: No MutationObserver for dynamic logo elements; relies on `seven:themechange` which fires **before** workspace DOM ready.  
**Reproduction**: Start in night theme; open workspace that injects `.app-icon`; switch to day; logo stays night.  
**Fix Direction**: Use `MutationObserver` on `document.body` for `.app-icon,.empty-logo` additions; or make logo a web component.  
**Regression Test**: Load workspace after theme set; assert logo matches current theme.

### A10-012 — LOW — VERIFIED
**Surface**: `release/beta-ui.css:12` — `.seven-mode-option` uses `grid-template-columns: 12px minmax(0,1fr) 22px`  
**Symptom**: `minmax(0,1fr)` with long text in `strong`/`small` causes overflow; no `text-overflow:ellipsis` on grid children.  
**Root Cause**: Grid item `min-width:0` missing on text container (2nd column).

**Fix Direction**: Add `min-width:0` to `.seven-mode-option>span:nth-child(2)`; add `overflow:hidden;text-overflow:ellipsis` to `strong`/`small`.

### A10-013 — LOW — STRONG
**Surface**: `release/build-release.cjs:152` — Fingerprint includes `workspaceDigest` but `workspaceFiles` order non-deterministic  
**Symptom**: `fs.readdirSync().sort()` is locale-dependent; `sort()` without locale → different order on different OS → different fingerprint for same source.  
**Root Cause**: `sort()` uses UTF-16 code units; `readdir` order varies by filesystem.  
**Reproduction**: Build on macOS vs Linux; compare fingerprints.  
**Fix Direction**: Use `sort((a,b)=>a.localeCompare(b,'en',{numeric:true}))` or explicit manifest.  
**Regression Test**: Build twice in same env; assert identical fingerprint.

### A10-014 — LOW — VERIFIED
**Surface**: `release/beta-ui-runtime.js:31` — `setMode()` clicks toggles programmatically  
**Symptom**: `dx.click()` / `sx.click()` triggers their `onclick` handlers which may call `setMode()` again → recursion risk.  
**Root Cause**: `deepThinkToggle`/`searchToggle` handlers (in `seven_ai-final.html`) call `u()` which calls `m()` which reads toggle state — but `click()` is sync, so state already flipped. No guard against re-entry.  
**Reproduction**: Call `setMode('research')` when already in research; observe double-toggle or stack overflow.  
**Fix Direction**: Check current mode before clicking; or use `dispatchEvent(new Event('click',{isTrusted:false}))` with guard in handler.  
**Regression Test**: Call `setMode(currentMode)` 10×; assert no recursion, mode stable.
