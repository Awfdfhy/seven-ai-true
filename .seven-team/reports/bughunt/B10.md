## Bugs Found (Sorted by Severity)

### B10-001  CRITICAL  VERIFIED
**Surface:** `beta-ui-runtime.js:36-38` `installStopFix()`  
**Symptom:** Stop button on Android does not abort generation; `stopRequested` variable undeclared (ReferenceError in strict mode).  
**Root Cause:** Line 38 assigns `stopRequested=true` without `let/const/var`; `isAndroid()` detection not evidenced; `activeAbortController` nulled instead of aborted on Android.  
**Reproduction:** Trigger generation on Android, tap stop — generation continues, console shows ReferenceError.  
**Fix Direction:** Declare `let stopRequested=false`; unify abort path using `AbortSignal`; remove platform branch or verify `isAndroid()` implementation.  
**Regression Test:** Unit test `installStopFix` with mocked `activeAbortController` and `isAndroid()` returning true/false; assert `abort()` called once.

### B10-002  HIGH  VERIFIED
**Surface:** `release/canon-simulator.js:149-151` debt accumulation  
**Symptom:** Canon debt threshold at 1.0 may be missed due to floating-point rounding (`toFixed(3)` → `Number()`).  
**Root Cause:** `Number((0.999 + 0.001).toFixed(3))` → `1` (OK), but `0.333+0.333+0.333` → `0.999` not `1.0`; threshold check `>=1` fails.  
**Reproduction:** Feed three scenes each adding `0.333` debt; `mustBranch` stays false despite logical threshold breach.  
**Fix Direction:** Use integer basis points (debt × 1000) or `Math.round((debt+add)*1000)/1000`; compare with epsilon.  
**Regression Test:** Property test adding random increments summing to ≥1.0; assert `mustBranch` true.

### B10-003  HIGH  STRONG
**Surface:** `release/attachment-runtime.js:24,27` file input handling  
**Symptom:** No file size/type limits; `accept="*/*"` + `multiple` allows arbitrary large files → OOM or UI freeze.  
**Root Cause:** `renderSelection` only stores metadata; no quota check; `build()` sets no `max-file-size` or `accept` restrict.  
**Reproduction:** Select 500 MB video; attachment strip renders but app may crash on subsequent send.  
**Fix Direction:** Enforce max total size (e.g., 25 MB) and per-file cap; restrict `accept` to image/*, application/pdf, text/*; show warning chip.  
**Regression Test:** E2E test selecting files exceeding limits; assert rejection toast and no strip entry.

### B10-004  HIGH  NEEDS_RUNTIME_TEST
**Surface:** Theme initialization race — `build-release.cjs:14` THEME_BOOT vs `beta-ui-runtime.js:19` `t()` vs `brand/runtime.js:1`  
**Symptom:** Flash of wrong theme/logo on cold start; `data-seven-theme` may flip twice.  
**Root Cause:** THEME_BOOT runs synchronously in `<head>`; `beta-ui-runtime.js` loads later and calls `t(1)` which dispatches `seven:themechange`; `brand/runtime.js` listens and swaps logo — three uncoordinated writers.  
**Reproduction:** Cold load on slow device; observe logo/theme flicker.  
**Fix Direction:** Single source of truth: THEME_BOOT writes `data-seven-theme` only; beta-ui `t()` reads only; brand listens only. Remove `t(1)` auto-dispatch on boot.  
**Regression Test:** Headless render capturing `documentElement.dataset.sevenTheme` at `DOMContentLoaded` and after 100 ms; assert single transition.

### B10-005  MEDIUM  VERIFIED
**Surface:** `beta-ui-runtime.js:23,31-32` mode picker state sync  
**Symptom:** `m()` reads DOM toggles; `setMode()` clicks toggles; `buildModePicker()` hides toggles (`display:none!important` at `beta-ui.css:12`) but `m()` still queries them — returns stale `chat` when picker active.  
**Root Cause:** `m()` depends on `#deepThinkToggle`/`#searchToggle` presence; CSS hides them when picker ready; `syncModePicker()` (unseen) must mirror state but not evidenced.  
**Reproduction:** Open picker, switch to Research, close picker, call `m()` — returns `chat`.  
**Fix Direction:** Move authoritative mode state to `S.mode`; `m()` returns `S.mode`; picker updates `S.mode` directly.  
**Regression Test:** Unit test `m()` after programmatic `setMode('research')` with picker mounted; assert `research`.

### B10-006  MEDIUM  STRONG
**Surface:** `release/control-bridge.js:1` `researchRowToClaim()` trust hardcoded + no sanitization  
**Symptom:** Claims created with `trust:'untrusted'` regardless of source authority; `row.claim.text` embedded without escaping — XSS if rendered via `innerHTML`.  
**Root Cause:** Line creates claim with `kind` derived from `row.status` but `trust` static; `text` passed through to `SevenControl.createClaim` unvalidated.  
**Reproduction:** Inject research row with `<img src=x onerror=alert(1)>` claim text; render in chat bubble.  
**Fix Direction:** Sanitize `text` at claim creation (escape HTML); derive `trust` from source authority metadata.  
**Regression Test:** Fuzz `row.claim.text` with HTML/JS payloads; assert output claim text is escaped.

### B10-007  MEDIUM  VERIFIED
**Surface:** `release/build-release.cjs:169-171` workspace path bytes  
**Symptom:** `workspacePathBytes` = max of four workspace bundles, but `base` (hub+css) counted in each — overstates actual lazy-load bytes for any single workspace.  
**Root Cause:** `paths` array adds `base` to each workspace; `Math.max` picks largest sum, but user loads only one workspace at a time.  
**Reproduction:** Build report shows `workspacePathBytes` ≈ 120 KB; actual lazy load for RPG is base + rpg + canon + world ≈ 60 KB.  
**Fix Direction:** Report per-workspace lazy bytes separately; keep `workspacePathBytes` as max for budgeting but label clearly.  
**Regression Test:** Build script asserts `workspacePathBytes` equals max of individually measured lazy loads.

### B10-008  MEDIUM  NEEDS_RUNTIME_TEST
**Surface:** `beta-ui-runtime.js:39,41` MutationObserver leaks  
**Symptom:** Observers on `#chat` and toggle buttons never disconnected on workspace unload or SPA navigation.  
**Root Cause:** `installMessageArrival()` and `w()` store observers in `S.messageObserver`/`S.observer` but no `disconnect()` call on teardown.  
**Reproduction:** Open/close workspace launcher 10×; heap snapshot shows 10 retained observers.  
**Fix Direction:** Add `cleanup()` exporting `S.messageObserver?.disconnect()`, `S.observer?.disconnect()`; call on `seven:workspace-close` or pagehide.  
**Regression Test:** Load/unload workspace in Puppeteer; assert observer count returns to zero.

### B10-009  LOW  VERIFIED
**Surface:** `beta-ui-runtime.js:17,21` localStorage theme quota  
**Symptom:** `localStorage.setItem('theme', x)` in `p(x)` and read in `f()` lack try/catch for `QuotaExceededError` (private browsing, full storage).  
**Root Cause:** Only `try/catch` around `getItem` in `f()`; `setItem` unguarded.  
**Reproduction:** Fill localStorage to quota; toggle theme — exception breaks theme persistence.  
**Fix Direction:** Wrap `setItem` in try/catch; fallback to in-memory `S.themePreference`.  
**Regression Test:** Mock `localStorage.setItem` to throw `QuotaExceededError`; assert no uncaught error.

### B10-010  LOW  STRONG
**Surface:** `release/attachment-runtime.js:27` ARIA menu semantics  
**Symptom:** Menu trigger `aria-haspopup="menu"` (valid) but menu items lack `tabindex="-1"`; `aria-expanded` set to string `'true'/'false'` not boolean.  
**Root Cause:** Manual ARIA attribute management without roving tabindex pattern.  
**Reproduction:** Keyboard open menu (Enter), arrow down — focus not trapped in menu.  
**Fix Direction:** Implement roving tabindex; set `aria-expanded` via `true/false` (coerced to string automatically).  
**Regression Test:** Axe-core scan on attachment menu open; assert zero violations.

### B10-011  LOW  NEEDS_RUNTIME_TEST
**Surface:** `brand/runtime.js:1` logo swap on `visibilitychange`  
**Symptom:** Logo re-fetched on every tab focus; if network fails, logo disappears.  
**Root Cause:** `visibilitychange` handler calls `s()` which sets `src` unconditionally; no cache-bust guard.  
**Reproduction:** Go offline, switch tabs — logo becomes broken image.  
**Fix Direction:** Only swap on `seven:themechange`; remove `visibilitychange` listener or guard with `navigator.onLine`.  
**Regression Test:** Offline tab switch; assert logo `src` unchanged and valid.

### B10-012  LOW  VERIFIED
**Surface:** `beta-ui-runtime.js:38` `stopRequested` typo  
**Symptom:** Variable `stopRequested` assigned but never declared; `requested` declared line 37 unused.  
**Root Cause:** Copy-paste error; `let requested=false` then `stopRequested=true`.  
**Reproduction:** Lint/TypeScript check catches; runtime ReferenceError in strict mode.  
**Fix Direction:** Rename `requested` → `stopRequested` or remove unused.  
**Regression Test:** ESLint `no-undef` rule passes.
