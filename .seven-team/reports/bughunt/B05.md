### B05-001 — RPG Workspace: State Persistence Race on Room Switch

**Severity:** CRITICAL  
**Confidence:** STRONG

**User symptom:** RPG session state (character, inventory, world position) lost or corrupted when switching rooms or reopening the workspace.

**Reproduction:** Open RPG workspace, create character, switch to another workspace, return — state is reset.  
**Fix direction:** Wire `roomPersistence` to `SevenWorld` or `SevenShell` lifecycle; implement actual save/load to `localStorage` or native secure store.  
**Regression test:** Add test in `release/world-runtime.test.cjs` that creates RPG state, simulates workspace unload/reload, asserts state restored.
